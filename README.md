# KomariDesktop 1.0

这是独立的 PySide6/Qt Widgets 桌面控件验证版，不使用 WebView2、QtWebEngine 或 Chromium。
默认以游客只读方式访问配置中的 Komari 地址，不需要 API Key，不修改 Komari 或服务器；首次运行请在设置中填写自己的地址，使用 `--demo` 参数可切回离屏演示数据。

当前源码版本标识 `1.0.3`，面向 Windows 10/11 的个人使用。六款皮肤与现有设置保持不变。本次修复桌面后层的事件恢复、最小化找回与节能、慢连接总超时和取消、无 RTT 时的丢包保留、设置失败回滚，并将全局快捷键默认改为较少冲突的三修饰键组合。Win+D、Explorer 重启和真实混合 DPI 多屏仍需在目标设备上人工验收。

桌面后层在 Windows 桌面宿主中绘制透明子窗口；Qt 面板保留为数据和快捷键控制器，变化时更新桌面画面。主动隐藏、调整模式和关闭中不会被自动恢复；桌面宿主不可用时保留用户偏好并回退到可见窗口。

退出时先取消网络请求、等待工作线程结束，再明确结束主事件循环，避免面板已经关闭而后台进程仍残留。

网络传输复用现有 PySide6 的 QtNetwork，保留批量状态请求与工作线程复用。每个请求有总时限，退出时可取消正在等待响应头或响应体的请求；HTTPS 证书校验保持开启。

## 安装与运行

### Windows 便携版（推荐）

从 GitHub Releases 下载实际提供的 Windows x64 ZIP，解压到一个普通用户目录，
双击 `run-KomariDesktop.cmd` 启动。程序不需要安装 Python、不需要管理员权限，也不会修改 Komari
服务器。首次运行后可按 `Ctrl+Shift+Alt+S` 打开设置。

发布包旁边的 `SHA256SUMS.txt` 用于校验下载文件；不要把发布包中的运行目录、日志或本地配置
重新提交到源码仓库。

### 从源码运行

需要 Windows x64、Python 3.12 和网络访问 PyPI：

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe main.py
```

演示数据和离屏回归：

```powershell
.\.venv\Scripts\python.exe main.py --demo
```

远程监控地址默认使用 HTTPS。仅在本机测试 HTTP 接口时使用
`--allow-insecure-http`；不要把带密码、Token、Cookie 或查询参数的 URL 写入配置或 Issue。

### 本地构建 Windows 便携版

在 Windows 上执行：

```powershell
python -m pip install -r requirements-dev.txt
powershell -ExecutionPolicy Bypass -File .\scripts\build-windows.ps1 -PythonPath python -SkipInstall
```

产物位于 `release/`，为 PyInstaller one-folder 目录压缩包。GitHub Actions 会在推送 `v*`
标签时运行同样的测试和构建，并把 ZIP 与 SHA256 校验文件附加到 Release。Windows 版必须在
Windows runner 上构建，不能用 WSL 产出可替代的 Windows 二进制。

## 设置与图层

- `Ctrl+Shift+Alt+S` 打开四页设置（窗口、分页、节点、快捷键）。调整模式的“设”按钮及系统托盘菜单也能进入；双击托盘图标打开设置。六项常用全局快捷键可以修改，重复组合、保留组合和Windows注册冲突会提示，冲突时恢复旧组合；固定页 `Ctrl+Alt+0–9` 也可单独关闭，避免占用其他软件组合键。
- 图层支持“桌面后层”“普通非置顶”“始终置顶”，托盘也可直接切换。桌面后层使用桌面图标宿主的透明子窗口，不修改壁纸；Win+D、Shell 重建和多屏变化仍需在实际环境验证。调整模式暂时显示原窗口便于拖动，退出后恢复所选图层。
- 图层仅在启动、用户明确切换、恢复显示和退出调整时应用；数据刷新、普通桌面点击不循环改层。原生命中过滤限定面板句柄，设置窗口和菜单不会被误判成鼠标穿透。
- 可设置锁定鼠标穿透、背景透明度、皮肤、逻辑尺寸、目标屏幕及角落/居中位置。没有可用托盘时，仍可通过快捷键或再次双击启动器进入设置；`open-settings.cmd` 也可直接打开设置。重复启动只唤醒现有实例，不创建第二块面板。
- 配置继续使用原有本地QSettings；不新增账号、服务器、依赖或管理员权限。

## 当前界面

- 当前支持参考图中的六款皮肤：1 雾白蜡棕、2 石墨键帽、3 夜行分段、4 冷灰对比、5 夜行色块、6 暖沙折线。六款皮肤不仅换色，还分别使用三网彩色卡片、深色卡片、全宽分段行、全宽横条行、紧凑色块行和真实采样趋势区；调整模式可用 T 或皮肤按钮循环切换。
- 真实状态默认每轮完成后 15 秒批量刷新一次，所有节点共用一次状态请求；节点基础信息缓存 5 分钟，后台复用一个工作线程和 TLS 证书配置。
- 卡片按节点复用；数值变化只更新相关控件，不重建整页、不重复套用主题、不把当前页跳回第一页。
- 每次成功数据刷新仍会完整重绘可见卡片；资源优化只针对不可见兼容控件、无变化的布局激活和重复样式事件，不跳过实时数据绘制。
- 参考绘制模式只同步当前皮肤需要的兼容控件；皮肤6趋势历史不再因 CPU/流量变化重复追加同一延迟样本，历史仍由真实采样记录统一维护。
- 重启时先显示最近缓存并明确标记过期，再异步连接真实数据。缓存只包含界面使用的字段，最多每分钟保存一次，不保存原始响应、公网 IP 或凭据。
- 网络中断时保留上次数据和更新时间，重试按 15/30/60/120/240/300 秒退避，成功后恢复正常频率；同一时间最多一轮请求。
- 隐藏面板后暂停界面更新与轮播，网络轮询降低至至少 60 秒一次；恢复显示时按数据新鲜度补刷。调整、设置窗口打开、固定节点时暂停自动翻页；演示和真实模式共用设置的轮播秒数。
- `refreshSeconds` 配置可在 5–300 秒之间设置，默认 15 秒。节点信息缓存不改变实时状态刷新频率。
- 设计稿基准为 440×526 逻辑像素面板（窗口含透明外边距为 452×538）。字号使用逻辑像素，Qt 处理系统 DPI；不再按窗口宽度二次放大整张画布。
- 基础指标保持一行；窄窗口把详情移到第二行，键帽/紧凑色块适当增高。自动布局在足够宽时增加为2–3列，仍保留单卡可读宽度；也可选择始终单列。分页按每行最大卡高计算，支持每页节点上限，不能靠压小字体强塞节点。
- 窗口过矮时优先保留名称、状态、CPU/内存和速率，减少延迟/详情展示；极端情况下用受控滚动兜底。断网保留上次数值并标记过期，不将带有读数的过期卡片立即折叠成离线摘要。
- 皮肤6恢复原稿180逻辑像素卡片（窄窗详情分行时198）及50px图高、155px详情基线，取消额外的标签圆点和斜引线。曲线保留运营商色，标签使用延迟/丢包等级色并完整显示丢包；网格恢复原稿实色与3/3虚线节距。底部页码空间不足时先省去排序文案，保留固定页状态。
- 真实趋势只使用本次会话成功请求中的观测值，每节点/运营商最多24点；历史独立于卡片，在翻页、换肤、隐藏时保留，删除节点时回收，不写入磁盘缓存。只有一个点时显示端点与“采样中”，不会扩展成整段水平历史；缺失或离线采样留断点。
- 延迟保留接口的有限浮点精度，仅在文字显示时取整。演示与真实历史共用24点横向映射；连接首次中断时插入缺口，连续失败不重复挤走旧历史。正常纵轴保持0–400ms；超过400ms时三网共用向上扩展的量程，并显示范围，不能将高延迟变化截成顶端直线。相近或稳定的真实数据仍可能贴合、平直，不添加人工波动或运营商偏移。
- 默认背景不透明以还原原稿底色，调整模式仍支持 40%–100% 背景透明度；100% 确实输出 alpha255。文字和指标保持不透明。
- 数字采用系统已有的 Bahnschrift，中文保持 Microsoft YaHei UI 回退。数字与 ms、%、KiB/s 分开绘制，速率较大时自动换算 MiB/s、GiB/s。
- 调整模式会显示轻量操作按钮：上一页/下一页、固定页、皮肤、透明度；皮肤 3/4/6 分别使用分段、横条和趋势线表达延迟，皮肤 2/5 使用深色芯片/色块表达。
- 调整模式工具栏可直接修改实时刷新间隔（5–300 秒）和自动轮播间隔（3–120 秒），两项设置都会保存；自动轮播关闭时也可以预先修改间隔。
- 在线、离线、数据过期、指标缺失使用不同状态，不用 0 冒充失败。
- 节点卡片支持按名称、CPU、内存、三网可用延迟均值排序；可按地区分组。固定后冻结有序节点ID，CPU排名和网络状态变化不会替换固定VPS；窗口缩小时仅在这个固定集合内部翻页。
- 调整模式下 Ctrl+点击卡片切换节点显示。设置中提供包含隐藏、离线和已选择但暂不可用节点的完整清单，可重新勾选、筛选、全选/清空，或自动显示全部及以后新增节点；空批次不冲掉手动选择。
- 页码输入支持超过9页直接跳转，手动翻页重置轮播倒计时。被动数据/容量变化优先保留首节点锚点，初次数据未到达前不覆盖上次保存页。调透明度与换肤不强制跳第一页。
- 屏幕工作区、分辨率、逻辑DPI和窗口跨屏变化触发去抖检查；选择最大相交工作区完整夹紧位置，支持负坐标显示器和拔屏后的找回。托盘“找回面板”可把面板移到鼠标所在屏幕并进入调整。真实混合缩放多屏仍需人工验证。

## 快捷键

- Ctrl+Shift+Alt+M：进入/退出调整模式。
- Ctrl+Shift+Alt+H：显示/隐藏面板。
- Ctrl+Shift+Alt+S：打开设置（以上六项常用组合可在设置中更改）。
- Ctrl+Shift+Alt+P：上一页节点；Ctrl+Shift+Alt+N：下一页节点，锁定模式也有效。
- Ctrl+Alt+1 到 Ctrl+Alt+9：从全部所选节点中跳转并固定该页节点；Ctrl+Alt+0：取消固定集合。该组全局快捷键可在设置中关闭。
- Ctrl+Shift+Alt+Q：退出验证版。
- 调整模式中：拖动面板、八方向边缘拉伸；Esc 退出。
- 调整模式中：[ 和 ] 调整透明度，S 切换排序，G 切换分组，C 开关轮播，N/P 或方向键翻页；1–9 固定对应页，0取消固定，F2打开设置。工具栏可直接修改刷新/轮播秒数。T 循环切换六款皮肤。
- 调整模式中滚轮可以翻页。
- 调整模式的工具栏提供上一页、下一页和固定/取消固定节点按钮。页码显示在底部状态栏；固定集合后自动轮播停止，集合在小窗口需分页时仍可用 P/N 手动切页；0取消固定后恢复全部所选节点。
- 程序使用临时目录单实例锁，重复启动不会创建第二个面板或争抢全局快捷键。

## Windows 验证

双击根目录的 `run-qt-probe.cmd`。若需要查看错误输出，双击 `run-qt-probe-debug.cmd`；若系统透明合成不可见，可运行 `run-qt-probe-opaque.cmd` 做普通不透明显示对照。离屏回归测试使用 `python main.py --demo`。
优先验证锁定模式下点击桌面、普通窗口、桌面图标时是否稳定；再验证 Ctrl+Shift+Alt+M、拖动、拉伸、缩放、多屏和高 DPI。

## 回归验证

`self_test.py` 检查 7 种窗口尺寸，`behavior_test.py` 检查布局和操作；`performance_regression.py` 使用本地 HTTP 替身验证缓存、退避、恢复、单并发和关闭边界。测试脚本会兼容旧的 `main.py` 与当前 `qt_main_redesign.py` 入口。测试使用独立的临时配置，不清空用户偏好。

`python tests/stability_regression.py` 使用离屏窗口、临时 INI 和回环 HTTP 服务，覆盖最小化恢复、桌面事件回调与去抖、主动隐藏/关闭不复活、最小化降频、设置失败回滚、完整丢包解析、慢响应总时限与取消，以及六款皮肤的七种尺寸。它不代替目标电脑上的真实 Win+D 验收。
`performance_probe.py --cycles 50` 用同样的演示数据测量刷新 CPU 时间、卡片创建与样式/绘制事件；添加 `--network` 可测 3 轮真实只读请求。

`verify_skin_fidelity.py` 是工作区的视觉验证工具，接收 `--reference` 指定原稿路径、`--output` 指定输出目录。它使用临时设置并禁用测试窗的桌面挂载/全局快捷键，输出六张原稿/程序并排图及 JSON 报告，验证像素字号、背景 alpha、绘图框边界、图条描边、趋势标签等级色和刷新后卡片实例稳定性。应使用与原稿相同的原生 2× 渲染查看对照图；自动检查通过不等于所有栅格像素完全相同。

`verify_skin6_live_layout.py` 使用隔离配置验证12组边界，包括同值采样、翻页换肤历史保留、隐藏与未显示节点采样、单点图、三个尺寸的标签/丢包/固定页、缺失断点、历史容量、浮点精度、超过400ms量程及断网缺口。皮肤6已撤回此前160px紧凑化调整，恢复180px原稿基准；原稿低延迟标签会裁切的地方仍作避让，保证三网与丢包完整可见。

`verify_v1_features.py` 使用临时设置、不可见Qt窗口及Windows API替身，覆盖16项功能检查：1/6/30/100节点与4个尺寸、多列/每页上限、窄窗调整、固定内容与断网、恢复保存页、节点重新选择、设置校验与保存、设置草稿取消、命中范围、图层调用计划、轮播计时和刷新不抢层。它不能代替真实Windows层级、Win+D、混合DPI/拔屏及合成闪烁的人工验收。

实现依据：[Microsoft SetWindowPos](https://learn.microsoft.com/en-us/windows/win32/api/winuser/nf-winuser-setwindowpos)、[Qt QSystemTrayIcon](https://doc.qt.io/qtforpython-6.8/PySide6/QtWidgets/QSystemTrayIcon.html)。系统API的能力不代表本机所有Shell行为已经实测。
